# CertiChain — Screenshots

Place screenshots here to populate the Screenshots section in the root [`README.md`](../../README.md).

## Naming convention

| Filename | Page |
|---|---|
| `01-landing.png` | Public landing page |
| `02-admin-dashboard.png` | Admin dashboard (university list + activity log) |
| `03-university-dashboard.png` | University dashboard (certificate list) |
| `04-issuance-wizard.png` | Certificate issuance wizard (any step) |
| `05-certificate-detail.png` | Certificate detail page |
| `06-verify-valid.png` | Public verification — VALID result |
| `07-verify-revoked.png` | Public verification — REVOKED result |
| `08-verify-not-found.png` | Public verification — NOT FOUND result |

## How to capture screenshots

1. Start the full local stack (see the root README installation guide).
2. Use your browser's built-in screenshot tool or a tool such as [Greenshot](https://getgreenshot.org/) (Windows).
3. Crop to the browser viewport only — no desktop chrome.
4. Save as PNG at a resolution of at least 1280 × 800.
5. Place the files in this directory using the filenames above.

The root README automatically embeds images from this path once the files are present.
